## Featured Project: LandscapingPro

### Landscaping Service Management System

I am developing LandscapingPro as my individual term project for CIS 641:
Software Analysis and Design.

The idea comes from my interest in starting a landscaping business.
The application will provide a public website where customers can explore
services, contact the company, and request a quote.

The business owner will have a private dashboard to manage customers,
services, quote requests, appointments, and jobs. Customers will be able
to provide details about their property and project, review quotes,
and view their appointments.

### Planned Features

- Browse landscaping services and pricing information.
- Submit quote requests with property and project details.
- Review and accept service quotes.
- View scheduled appointments.
- Manage customers, services, quotes, and jobs through an admin dashboard.

### Planned Technologies

React, ASP.NET Core Web API, Entity Framework Core, and SQL Server.

### What I Am Learning

This project allows me to practice gathering requirements, creating system
models, designing a database, and planning a full-stack application.
